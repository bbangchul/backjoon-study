# 스택 정리 노트

LIFO(Last In, First Out): 마지막에 넣은 값을 먼저 꺼냅니다.

```text
Push(2), Push(5), Push(3)

       Push / Pop
           |
           v
        +-----+
        |  3  |  <- 마지막으로 넣은 값
        +-----+
        |  5  |
        +-----+
        |  2  |
        +-----+

Pop 순서: 3 -> 5 -> 2
```

### 배열 스택

`top`은 **다음 삽입 위치**이며 현재 원소 개수와 같습니다.

```text
인덱스:   0   1   2   3   4
storage: [2] [5] [3] [?] [?]
                     ^
                    top=3
마지막 원소: storage[top - 1] == 3
```

```cpp
IsEmpty(): top == 0
IsFull():  top == size
Push(el):  storage[top++] = el;  // 저장 후 증가
Pop():     return storage[--top]; // 감소 후 읽기
Top():     return storage[top - 1]; // 삭제하지 않고 읽기
```

`Push`는 가득 찼으면 false, 성공하면 true를 반환합니다.
`Pop`과 `Top`은 빈 스택이면 0을 반환합니다. 데이터 0과 구분하려면 `IsEmpty`를 먼저 확인합니다.

### 포인터 스택

`top`은 마지막으로 삽입한 노드의 주소입니다.

```text
top --> [3|next] --> [5|next] --> [2|0]

Push(7)
top --> [7|next] --> [3|next] --> [5|next] --> [2|0]

Pop() -> 7 반환, 첫 노드 해제
top --> [3|next] --> [5|next] --> [2|0]
```

```cpp
Push: top = new node(el, top);
Pop:  기존 top 저장 -> top을 next로 이동 -> 기존 노드 delete
```

빈 상태는 `top == 0`입니다. `IsFull()`은 고정 용량 제한이 없어 항상 false를 반환합니다.
실제 메모리 할당 실패는 `new`의 예외로 처리됩니다.

### 문자열 뒤집기

문자를 입력 순서로 Push한 뒤 모두 Pop하면 역순이 됩니다.

```text
입력: h -> e -> l -> l -> o
출력: o -> l -> l -> e -> h
```

현재 예제의 용량은 30바이트입니다. 바이트를 뒤집으므로 영문 같은 단일 바이트 문자열에 사용합니다.

### WFF: 괄호 짝 검사

여는 괄호를 Push하고, 닫는 괄호가 나오면 Top과 짝을 비교한 뒤 Pop합니다.

```text
입력     스택 (왼쪽이 바닥)     처리
(        (                    Push
[        ( [                  Push
]        (                    [와 ] 일치 -> Pop
)        비어 있음             (와 ) 일치 -> Pop
```

닫는 괄호에서 스택이 비었거나 짝이 다르면 실패입니다.
입력이 끝난 뒤에도 여는 괄호가 남아 있으면 실패입니다.
현재 코드는 괄호 외의 문자를 무시하며, 빈 입력은 WFF로 판정합니다.

## 전체 코드

각 코드 블록은 **별도의 완전한 프로그램**입니다. 서로 합치지 않고 하나씩 컴파일합니다.
같은 내용을 `코드/` 폴더의 `.cpp` 파일에도 저장했습니다. 원래 수업 폴더는 유지했습니다.

이 폴더에서 다음처럼 실행합니다(C++11 이상).

### 배열 스택

기존 통합 main.cpp의 전체 코드입니다. 함수 테스트 결과를 먼저 출력합니다.

[코드 파일](코드/stack_array.cpp)

```sh
c++ -std=c++11 코드/stack_array.cpp -o /tmp/stack_array
/tmp/stack_array
```

```cpp
#include <iostream>
using namespace std;

// ===== stack.h 영역 시작 =====
// [알고리즘 E.1] 배열 스택

class Stack
{
public:
    Stack(int s = 100)
    {
        size = s;
        storage = new int[size];
        top = 0; // 다음에 삽입할 위치이자 현재 원소 개수
    }
    ~Stack() { delete[] storage; }
    Stack(const Stack &) = delete;
    Stack &operator=(const Stack &) = delete;

    bool IsEmpty() { return top == 0; }
    bool IsFull() { return top == size; }
    bool Push(int el);
    int Pop();
    int Top();

private:
    int *storage;
    int top;
    int size;
};
// ===== 여기까지 stack.h 영역 =====

// ===== stack.cpp 영역 시작 =====
// [알고리즘 E.2]

bool Stack::Push(int el)
{
    if (IsFull())
        return false;
    storage[top++] = el;
    return true;
}

int Stack::Pop()
{
    if (IsEmpty())
        return 0;
    return storage[--top];
}

int Stack::Top()
{
    if (IsEmpty())
        return 0;
    return storage[top - 1];
}
// ===== 여기까지 stack.cpp 영역 =====

// ===== 실행 예제 영역 시작 =====
int main()
{
    cout << boolalpha;
    Stack test(2);
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    cout << "Push(10): " << test.Push(10) << endl;
    cout << "Push(20): " << test.Push(20) << endl;
    cout << "IsFull: " << test.IsFull() << endl;
    cout << "Top: " << test.Top() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    return 0;
}
```

[코드 파일](코드/stack_pointer.cpp)

```cpp
#include <iostream>
using namespace std;

// ===== node.h 영역 시작 =====
// [알고리즘 E.5]

class node
{
public:
    node(int d, node *n = 0)
    {
        next = n;
        data = d;
    }
    // 학습 편의를 위해 모두 public으로 둔다.
    node *next;
    int data;
};
// ===== 여기까지 node.h 영역 =====

// ===== stack.h 영역 시작 =====
// [알고리즘 E.6]

class Stack
{
public:
    Stack();
    ~Stack();
    Stack(const Stack &) = delete;
    Stack &operator=(const Stack &) = delete;
    bool IsEmpty();
    bool IsFull();
    bool Push(int el);
    int Pop();
    int Top();

private:
    node *top;
};
// ===== 여기까지 stack.h 영역 =====

// ===== stack.cpp 영역 시작 =====
// [알고리즘 E.7]

Stack::Stack()
{
    top = 0;
}

Stack::~Stack()
{
    while (!IsEmpty())
        Pop();
}

bool Stack::IsEmpty()
{
    return top == 0;
}

bool Stack::IsFull()
{
    return false; // 고정 용량 제한 없음 (메모리 할당 실패 시 new가 예외 발생)
}

bool Stack::Push(int el)
{
    if (IsFull())
        return false;
    top = new node(el, top);
    return true;
}

int Stack::Pop()
{
    if (IsEmpty())
        return 0;
    node *ptr = top;
    top = top->next;
    int el = ptr->data;
    delete ptr;
    return el;
}

int Stack::Top()
{
    if (IsEmpty())
        return 0;
    return top->data;
}
// ===== 여기까지 stack.cpp 영역 =====

// ===== 실행 예제 영역 시작 =====
int main()
{
    cout << boolalpha;
    Stack test;
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    cout << "Push(10): " << test.Push(10) << endl;
    cout << "Push(20): " << test.Push(20) << endl;
    cout << "IsFull: " << test.IsFull() << endl;
    cout << "Top: " << test.Top() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    return 0;
}
```

### WFF 괄호 검사

기존 통합 main.cpp의 전체 코드입니다. 함수 테스트 결과를 먼저 출력합니다.

[코드 파일](코드/stack_wff.cpp)

```sh
c++ -std=c++11 코드/stack_wff.cpp -o /tmp/stack_wff
/tmp/stack_wff
```

한 줄 입력 예: `([]){}` → 마지막 출력 `WFF!!`

```cpp
#include <iostream>
using namespace std;

// ===== node.h 영역 시작 =====
// [알고리즘 E.5]

class node
{
public:
    node(int d, node *n = 0)
    {
        next = n;
        data = d;
    }
    // 학습 편의를 위해 모두 public으로 둔다.
    node *next;
    int data;
};
// ===== 여기까지 node.h 영역 =====

// ===== stack.h 영역 시작 =====
// [알고리즘 E.6]

class Stack
{
public:
    Stack();
    ~Stack();
    Stack(const Stack &) = delete;
    Stack &operator=(const Stack &) = delete;
    bool IsEmpty();
    bool IsFull();
    bool Push(int el);
    int Pop();
    int Top();

private:
    node *top;
};
// ===== 여기까지 stack.h 영역 =====

// ===== stack.cpp 영역 시작 =====
// [알고리즘 E.7]

Stack::Stack()
{
    top = 0;
}

Stack::~Stack()
{
    while (!IsEmpty()) Pop();
}

bool Stack::IsEmpty()
{
    return top == 0;
}

bool Stack::IsFull()
{
    return false; // 고정 용량 제한 없음 (메모리 할당 실패 시 new가 예외 발생)
}

bool Stack::Push(int el)
{
    if (IsFull()) return false;
    top = new node(el, top);
    return true;
}

int Stack::Pop()
{
    if (IsEmpty()) return 0;
    node *ptr = top;
    top = top->next;
    int el = ptr->data;
    delete ptr;
    return el;
}

int Stack::Top()
{
    if (IsEmpty()) return 0;
    return top->data;
}
// ===== 여기까지 stack.cpp 영역 =====

// ===== 실행 예제 영역 시작 =====
// [알고리즘 E.8] 잘 갖춰진 괄호 식의 판별

bool Match(char a, char b)
{
    if (a == '(' && b == ')') return true;
    if (a == '[' && b == ']') return true;
    if (a == '{' && b == '}') return true;
    return false;
}

int main()
{
    cout << boolalpha;
    Stack test;
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    cout << "Push(10): " << test.Push(10) << endl;
    cout << "Push(20): " << test.Push(20) << endl;
    cout << "IsFull: " << test.IsFull() << endl;
    cout << "Top: " << test.Top() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "Pop: " << test.Pop() << endl;
    cout << "IsEmpty: " << test.IsEmpty() << endl;
    cout << "=== 괄호 검사: 한 줄 입력 ===" << endl;
    Stack stack;
    char c;
    bool valid = true;
    while (cin.get(c) && c != '\n')
    {
        if (c == '(' || c == '[' || c == '{')
            stack.Push(static_cast<int>(c));
        else if (c == ')' || c == ']' || c == '}')
        {
            if (stack.IsEmpty() || !Match(static_cast<char>(stack.Top()), c))
            {
                valid = false;
                break;
            }
            stack.Pop();
        }
    }
    if (valid && stack.IsEmpty()) cout << "WFF!!" << endl;
    else cout << "Not a WFF!!" << endl;
    return 0;
}
```

## 시간복잡도

n은 현재 원소 개수이며, 메모리 할당 비용은 별도입니다.

| 함수 | 배열 | 포인터 |
| --- | --- | --- |
| IsEmpty / IsFull / Top | O(1) | O(1) |
| Push / Pop | O(1) | O(1) |

길이 m인 문자열 뒤집기와 괄호 검사의 시간은 O(m)입니다.
소멸자는 배열을 해제하거나 남은 연결 노드를 차례로 해제합니다.
