# 배열 리스트: 코드와 그림으로 이해하기

> 2026-10-30 실행 검토: cpp의 중복 클래스 정의를 제거했습니다. `GetAt`은 음수 인덱스도 검사하여 -1을 반환하도록 수정했습니다. 아래 원본 코드와 오류 설명 중 이 수정에 해당하는 부분은 수정 전 동작을 설명합니다.

이 문서는 같은 폴더의 `list.cpp`, `list.h`를 설명합니다. 함수별 코드 블록은 현재 소스에서 가져온 것입니다. 이 리스트는 정수를 오름차순으로 저장하며, 배열 안에서 값을 이동시켜 삽입·삭제합니다.

## 1. 배열의 크기와 실제 데이터 개수는 다르다

```cpp
int LMAX;
int *arr;
int size;
```

LMAX는 최대 저장 개수, size는 현재 저장 개수입니다. arr는 동적으로 할당한 정수 배열의 첫 원소를 가리킵니다. 연결 리스트의 next_처럼 다음 노드 주소를 담는 필드는 없습니다.

아래 그림은 최대 6개까지 저장할 수 있지만 현재 3개만 저장된 상태입니다.

```text
LMAX = 6, size = 3

인덱스    0     1     2     3     4     5
        +-----+-----+-----+-----+-----+-----+
arr --->|  2  |  3  |  5  |  ?  |  ?  |  ?  |
        +-----+-----+-----+-----+-----+-----+
         <--- 유효 값 ---> <--- 미사용 공간 --->
```

`?`는 현재 리스트 데이터로 사용하지 않는 자리입니다. `new int[lsize]`는 각 칸을 0으로 초기화하지 않으므로, 아직 값을 넣지 않은 칸을 유효 데이터처럼 읽으면 안 됩니다.

유효한 인덱스는 `0 <= index < size`입니다. 배열에 할당된 공간이 있더라도 index가 size 이상인 칸은 현재 리스트의 원소가 아닙니다. 예를 들어 위 그림에서 arr[3]은 할당된 공간 안에 있지만, 아직 리스트의 네 번째 값은 없습니다.

```text
lst ---> list 객체
         +------------------+
         | LMAX = 6         |
         | size = 3         |
         | arr -------------+---> [2][3][5][?][?][?]
         +------------------+
```

`lst`는 list 객체를, arr는 배열을 가리킵니다. 배열은 같은 종류의 값이 메모리에 연속해서 놓이므로 `arr[index]`로 해당 위치에 바로 접근할 수 있습니다.

## 2. list(lsize): 저장 공간을 만들고 빈 상태로 시작

```cpp
list::list(int lsize)
{
    arr = new int[lsize];
    LMAX = lsize;
    size = 0;
}
```

헤더의 선언은 `list(int lsize = 100)`입니다. 인수를 생략한 `new list()`는 최대 100개를 저장할 공간을 만듭니다. 구현부에는 기본 인수를 다시 쓰지 않습니다.

```text
list(5) 호출

1. arr = new int[5] -> 정수 5개를 담을 공간 확보
2. LMAX = 5        -> 최대 개수 기록
3. size = 0        -> 현재는 값이 하나도 없음

인덱스    0     1     2     3     4
        +-----+-----+-----+-----+-----+
arr --->|  ?  |  ?  |  ?  |  ?  |  ?  |
        +-----+-----+-----+-----+-----+
size = 0: 위 칸 중 현재 데이터로 사용하는 칸은 없음
```

배열을 생성했다는 것과 값을 저장했다는 것은 다릅니다. 이 생성자는 음수 lsize를 검증하지 않으므로 학습 예제에서는 유효한 용량을 사용한다고 가정합니다.


## 3. GetSize(): 현재 개수를 바로 반환

```cpp
int list::GetSize()
{
    return size;
}
```

size를 삽입·삭제 때 갱신하기 때문에 전체 배열을 세지 않습니다.

```text
arr: [2][3][5][?][?]
size = 3

GetSize() -> size 읽기 -> return 3
```

LMAX가 100이어도 현재 3개만 넣었다면 반환값은 3입니다. size는 개수이고 마지막 유효 인덱스는 size - 1입니다.


## 4. GetAt(position): 지정한 인덱스의 값 읽기

```cpp
int list::GetAt(int position)
{
    if (size <= position)
        return -1;
    return arr[position];
}
```

헤더에는 매개변수 이름이 index이고 구현에는 position이지만, 둘 다 호출자가 전달한 인덱스를 뜻합니다. 선언과 정의의 매개변수 이름이 달라도 자료형이 같으면 괜찮습니다.

```text
인덱스:    0     1     2
arr:      [2]   [3]   [5]       size = 3

GetAt(1) -> 3 <= 1 ? 거짓 -> arr[1] -> 3
GetAt(3) -> 3 <= 3 ? 참   -> -1
```

size와 같은 인덱스도 사용할 수 없습니다. 인덱스가 0부터 시작해서 마지막 값은 arr[size - 1]에 있기 때문입니다.

### 음수 인덱스는 현재 코드에서 검사하지 않는다

`GetAt(-1)`에서는 `size <= -1`이 거짓이 되어 arr[-1]에 접근합니다. 이는 배열 앞쪽 범위를 벗어난 접근입니다. 검사하려면 다음처럼 하한도 확인해야 합니다. 아래는 설명용 개선 예시이고 원본에는 적용하지 않았습니다.

```cpp
if (position < 0 || position >= size)
    return -1;
```

또한 -1을 데이터로 넣을 수 있어서 실제 값 -1과 실패 반환값 -1은 구분되지 않습니다.


## 5. Index(value): 값의 위치를 차례로 찾기

```cpp
int list::Index(int value)
{
    for (int i = 0; i < size; i++)
        if (value == arr[i])
            return i;
    return -1;
}
```

인덱스 0부터 size - 1까지 차례대로 값을 비교합니다. 같으면 즉시 그 인덱스를 반환합니다.

```text
Index(5), size = 3

i=0: arr[0] = 2 -> 5와 다름
         [2][3][5]
          ^
i=1: arr[1] = 3 -> 5와 다름
         [2][3][5]
             ^
i=2: arr[2] = 5 -> 같음 -> return 2
         [2][3][5]
                ^
```

없는 값은 반복이 끝난 뒤 -1을 반환합니다. 빈 리스트는 size가 0이라 한 번도 비교하지 않습니다. 중복 값이 있으면 가장 앞의 인덱스를 반환합니다. 배열이 정렬되어 있지만 이 함수는 이진 탐색이 아니라 순차 탐색입니다.


## 6. Find(value): 값이 있는지만 확인

```cpp
int list::Find(int value)
{
    return Index(value) != -1;
}
```

Index의 결과를 이용해 존재 여부를 반환합니다. 함수 반환형은 int이므로 비교 결과 true는 1, false는 0으로 반환됩니다.

```text
arr: [2][3][5]

Find(3)
  -> Index(3) = 1
  -> 1 != -1 이 참
  -> return 1 (있음)

Find(9)
  -> Index(9) = -1
  -> -1 != -1 이 거짓
  -> return 0 (없음)
```

Find의 0은 “0번째 위치”가 아니라 “값이 없음”입니다. 위치가 필요하면 Index를, 있는지만 궁금하면 Find를 사용합니다.


## 7. Insert(item): 큰 값들을 오른쪽으로 밀어 자리 만들기

```cpp
void list::Insert(int item)
{
    int i;
    if (size == LMAX)
        return;
    for (i = size; 0 < i; i--)
    {
        if (item < arr[i - 1])
            arr[i] = arr[i - 1];
        else
            break;
    }
    arr[i] = item;
    size++;
}
```

먼저 size와 LMAX가 같은지 검사합니다. 이미 꽉 찼으면 값을 넣지 않고 return합니다. 배열을 자동으로 늘리는 코드는 없습니다.

빈칸을 만들 때는 **오른쪽 끝부터 왼쪽 방향으로 검사**합니다. 새 값보다 큰 기존 값은 오른쪽으로 한 칸 복사합니다.

### [2, 5, 7]에 Insert(3)

```text
LMAX = 5, 기존 size = 3

인덱스    0     1     2     3     4
시작     [2]   [5]   [7]   [?]   [?]
                          i=3 (첫 미사용 칸)

1. i=3: 3 < arr[2](7) -> 참
   arr[3] = arr[2]
         [2]   [5]   [7]   [7]   [?]
                      +---->+

2. i=2: 3 < arr[1](5) -> 참
   arr[2] = arr[1]
         [2]   [5]   [5]   [7]   [?]
                +---->+

3. i=1: 3 < arr[0](2) -> 거짓 -> break
   삽입할 위치 i는 1

4. arr[1] = 3
         [2]   [3]   [5]   [7]   [?]

5. size++ -> size = 4
```

이동 중 값이 잠시 중복되는 것은 복사하기 때문입니다. 마지막에 새 값을 써 넣으면 원하는 결과가 됩니다. 왼쪽부터 밀면 아직 옮기지 않은 다음 값을 덮어쓸 수 있어서 오른쪽부터 이동합니다.

### 맨 앞에 Insert(1)

```text
전: [2][3][5][?]
    [2][3][5][5]  <- 5 복사
    [2][3][3][5]  <- 3 복사
    [2][2][3][5]  <- 2 복사
후: [1][2][3][5]  <- i=0에 1 저장
```

i가 0이 되면 조건 `0 < i`가 거짓이라 arr[-1]을 검사하지 않습니다.

### 맨 뒤, 빈 배열, 같은 값

```text
Insert(7): [2][3][5][?] -> [2][3][5][7]
                       기존 마지막 값보다 커서 바로 break

빈 리스트에 Insert(2): [?][?] -> [2][?]
                       size=0이라 반복 생략, arr[0]에 저장

Insert(3): [2][3][5][?] -> [2][3][3][5]
                       5만 밀고 기존 3 뒤에 새 3을 저장
```

비교가 `<`이므로 같은 값은 밀지 않습니다. 새 값은 기존 같은 값들 뒤에 놓입니다. 성공한 삽입에서만 size가 1 증가합니다. `size < LMAX`일 때 arr[size]는 할당 범위 안의 빈칸이므로 거기에 복사해도 괜찮습니다.


## 8. Delete(value): 삭제 후 뒤쪽 값을 왼쪽으로 당기기

```cpp
void list::Delete(int value)
{
    int i;
    for (i = 0; i < size; i++)
        if (value == arr[i])
            break;
    if (i == size)
        return;
    size--;
    for (; i < size; i++)
        arr[i] = arr[i + 1];
}
```

첫 반복문은 삭제할 값의 인덱스를 찾습니다. break는 반복문만 종료하며 함수 전체를 끝내지는 않습니다. 찾지 못하면 i가 size와 같아지고 return합니다.

### [2, 3, 5, 7]에서 Delete(3)

```text
시작: size = 4
인덱스    0     1     2     3     4
         [2]   [3]   [5]   [7]   [?]
                ^
                i=1에서 발견

1. size-- -> size = 3
   이제 최종 유효 범위는 인덱스 0,1,2가 될 예정

2. i=1: arr[1] = arr[2]
         [2]   [5]   [5]   [7]   [?]
                <----+

3. i=2: arr[2] = arr[3]
         [2]   [5]   [7]   [7]   [?]
                      <----+

4. i=3: i < size(3)가 거짓 -> 종료

최종:    [2]   [5]   [7]  |[7]   [?]
          <유효 데이터>  | 미사용 공간
```

마지막 칸에 7이 남아 있어도 리스트에 7이 두 개 있는 것은 아닙니다. size가 3이므로 인덱스 3의 값은 더 이상 유효 데이터가 아닙니다. 이 함수는 배열 자체의 크기를 줄이거나 마지막 칸을 0으로 지우지 않습니다.

### 첫 값과 마지막 값 삭제

```text
Delete(2): [2][3][5] -> [3][5] | [5]
                       뒤의 두 값을 왼쪽으로 당김

Delete(5): [2][3][5] -> [2][3] | [5]
                       size만 감소, 이동할 뒤쪽 값 없음

Delete(9): [2][3][5] -> 그대로 (못 찾음)

단 하나의 값 삭제: [2] -> size=0 (빈 리스트)
```

이동은 왼쪽부터 오른쪽 순서로 해야 아직 읽어야 할 값을 보존할 수 있습니다. 같은 값이 여러 개 있으면 가장 앞의 한 개만 삭제합니다. `delete` 연산자는 사용하지 않습니다. 저장 공간은 유지하고 값의 배치와 size만 바꾸는 삭제입니다.


## 9. main(): 네 개를 넣고 개수 출력

```cpp
int main()
{
    list *lst = new list();
    lst->Insert(2);
    lst->Insert(3);
    lst->Insert(5);
    lst->Insert(7);
    cout << lst->GetSize();
}
```

매번 Insert가 size를 증가시키므로 마지막 GetSize는 4를 반환합니다.

```text
호출          유효 데이터            size
new list()    없음                   0 (LMAX=100)
Insert(2)     [2]                    1
Insert(3)     [2][3]                 2
Insert(5)     [2][3][5]              3
Insert(7)     [2][3][5][7]           4
GetSize()                            4 반환
```

`lst`는 list 객체의 주소를 담으므로 `lst->Insert(...)`처럼 `->`를 사용합니다. 객체를 `list lst;`로 직접 만들었다면 `lst.Insert(...)`처럼 점을 사용합니다. 현재 출력은 4이며 줄바꿈은 없습니다.


## 10. 원본 코드의 한계와 연결 리스트와의 비교

현재 헤더와 cpp에 같은 list 클래스 정의가 있어 그대로 컴파일하면 재정의 문제가 발생합니다. 일반적으로 클래스 정의는 헤더에만 두고 cpp에는 함수 구현을 둡니다.

현재 클래스에는 소멸자가 없어 arr를 `delete[]`로 해제하는 처리가 없습니다. main의 list 객체도 new로 만들고 해제하지 않습니다. `delete lst`만으로는 동적으로 할당한 arr까지 해제되지 않으므로 소멸자에서 `delete[] arr`를 수행해야 합니다. 이 문서는 설명을 추가한 것이며 원본 실행 코드는 수정하지 않았습니다.

| 관점 | 배열 리스트 | 단일 연결 리스트 |
| --- | --- | --- |
| 값 저장 방식 | 연속한 배열 칸 | 따로 만들어 연결한 노드 |
| 다음 값으로 이동 | 인덱스 증가 | next_ 따라 이동 |
| GetAt | 인덱스로 바로 접근 | 첫 노드부터 순서대로 이동 |
| 삽입 | 뒤의 값을 오른쪽으로 복사 | 새 노드를 만들고 next_ 변경 |
| 삭제 | 뒤의 값을 왼쪽으로 복사 | 연결을 우회한 뒤 노드 해제 |
| 현재 개수 | size에 기록 | 매번 노드를 세어 계산 |
| 최대 저장 공간 | 생성 때 정한 LMAX | 고정 용량 멤버 없음, 메모리 할당 필요 |

## 11. 함수별 소요 시간

| 함수 | 시간 | 이유 |
| --- | --- | --- |
| 생성자 | 배열 공간 할당 | lsize개 공간을 요청하며 실제 할당 비용은 환경에 따라 다르다. |
| GetSize | O(1) | size만 읽는다. |
| GetAt | O(1) | 인덱스로 바로 접근한다. |
| Index / Find | 최악 O(n) | 값을 차례로 비교한다. |
| Insert | 최악 O(n) | 맨 앞 삽입이면 모든 기존 값을 이동한다. |
| Delete | 최악 O(n) | 값을 찾고 뒤의 값을 이동한다. |

n은 현재 저장된 개수입니다. 배열 리스트에서는 “어느 칸이 유효한가?”, “어느 방향으로 복사하는가?”, “size가 언제 바뀌는가?”를 함께 확인하면 흐름을 이해하기 쉽습니다.
